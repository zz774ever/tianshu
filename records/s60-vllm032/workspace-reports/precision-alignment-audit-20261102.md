## 结论

**已经执行过 NVIDIA 对照，但没有达到完整的严格精度对齐通过标准。** 原 Qwen3-0.6B 任务后来按用户明确接受已知数值差异的决定结束精度排查，应记录为“已知差异经用户接受”，不能记为 Tier 1 全通过。

27B/35B 的 103/104 请求是 S60 功能与质量 Gate 的结果，不是与 NVIDIA 上游的逐 token 精度对齐结果。本次所查产物中，没有发现这两种大模型相应的 NVIDIA 输出与完整精度比较结果。

## 1. 核对的要求

要求来源：安装目录中的 `flagscale_agent/skills/infer-precision-check/SKILL.md`，并结合已审阅的 FlagScale Agent 官方版本。它规定：

- 参考端为 NVIDIA 加 upstream vLLM，目标硬件不能当作 ground truth。
- 相同权重、tokenizer，greedy（temperature=0），先 TP1，再扩展部署 TP；保存双方 token ID、文本与日志。
- Tier 1：严格 token 一致；特别要求前 10 token。
- Tier 2：对适用的后段数值差异，参考 token 必须在每个位置的 Top-5 候选中。
- Tier 3：符合限定条件时逐提示词判断语义等价，并记录采用等级。
- 多模态模型需增加图片输入的参考对照；服务和部署 TP 也有相应验证要求。

用户原始限定的 Qwen3-0.6B 精度工作，与后续 27B/35B 完整后端验证范围应分别表述。

## 4. 三个等级是否可以记为通过

### Tier 1

**不通过。** 原 BF16 和生产 RMS 候选 BF16 都在算术第 7 token 分歧，位于要求严格匹配的前 10 token 内；不能用“BF16 后段漂移”直接豁免。

### Tier 2

**尚无完整通过证据。** 本次核验发现，各记录的首个分歧位置上，参考 token 在目标候选中为第 2 名。但技能要求每个适用位置都满足 Top-5，`analyze_decode_precision.py` 只专门分析首个分歧，不能把一个位置的结果当作整段通过。

原始输出保留了各步候选数据，因此不是完全缺少候选数据。不过，两侧一旦选出不同 token，后续独立生成的输入历史也不同；若进一步作因果或对齐判断，应明确比较协议，不能不加说明地把相同序号当作同一输入条件。现有记录未给出完整、适用且有明确结论的 Tier 2 验收报告。算术第 7 token 的 Tier 1 失败仍单独存在。

### Tier 3 / 用户接受

会话原文中确有用户指令：**“这个精度差异是可以接受的”**。据此停止原 0.6B 差异深挖有授权，且状态与使用说明保留了严格对齐失败。

这支持“按用户决定接受已知差异收尾”的表述，但不自动生成逐提示词的完整 Tier 3 评审，也不等于用户豁免后续所有模型与所有功能/质量失败。

## 5. 27B/35B 的 Gate 与精度验收

现有 Gate 汇总为：27B eager、27B Graph、35B Graph 各 26/26；35B eager 25/26，合计 103/104。它们检查完成生成、文本/图片语义、并发、输出异常等。

本次未发现 27B/35B 使用相同权重、相同输入和生成条件的 NVIDIA 逐 token 参考产物，以及相应的 Tier 1/2/3 结论。它们包含多模态与 TP2 路径，不能把 0.6B 的 TP1 对照自动推广过去。

35B eager 的 `limitations` 关键词失败是尚未解决的质量 Gate 项；当前没有证据证明它必然是某个硬件算子精度错误，也不能因用户接受了 0.6B 差异就将其判为通过。

## 6. 其他过程缺口与判断范围

- 实际使用的是两条标准开头加算术、中文、代码的自选五提示词，未逐条复现技能所列的完整标准五提示词；若验收合同要求完全一致的标准集，还需单列这个覆盖差异。
- 精度资料位于 `/workspace/s60-adaptation/`，而技能示例使用 `/workspace/adapt-logs/`。资料实际已保存，不能因不同目录就说未执行；后续报告应链接真实路径。
- 存在模型文件哈希与 NVIDIA 环境证据，不应再将此前有待搭建参考端的早期状态当作当前事实。
- CPU FP64 是诊断参考，不能代替 NVIDIA 真值。最后实际 NVIDIA fused RMS 的边界值与独立 GCU 相同，不能据 CPU FP64 单点差异宣称 GCU 一定错误。

本次请求是检查已有执行与证据，不据此重新启动已接受的精度深挖。若后续要求严格按官方精度等级交付，则应先明确模型、精度等级、提示词与部署配置，再补对应验收，而不是继续无范围地调试。
